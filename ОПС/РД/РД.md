# 🛠️ Главная Опись Уклада **Родов** ***Светоча***

Уклад **Родов** является главным строительным сводом основ Чеки, определяющим правила созидания, соразмерности и упорядочивания всех внутренних устроев данных и знаковых сред.

---



## 💡 Ключевые возможности:

* **Единый уклад алгоритмических выражений:** обеспечивает использование логических выражений при создании программного обеспечения как посредством низкоуровневого языка программирования `S`, так и посредством высокоуровневого языка программирования `C`, в том числе порознь или в их неразрывном соитии;
* **СПЛАВ - (Соединение Программных Логических Алгоритмических Выражений); SPLAV - (System Purpose for Logical Assembly Verticals); ***GASM*** - (GNU Assembler Magic)** - самобытный уклад алгоритмических выражений, обеспечивающий при создании программного обеспечения формирование единых человекачитаемых форм посредством бесшовного соединения программных логических выражений низкоуровневого языка программирования `S` и высокоуровневого языка программирования `C`. Этому диву ***Сплав*** обязан не только зодческому укладу ***Светоча***, но и, не в меньшей мере, инструментам ***GCC***, в числе которых `cc1` (`C` укладчик `GCC`) и `gas` (`S` сборщик `GNU GAS`), чья скрытая мощь воистину безгранична, а качество уложения поражает воображение;
* **Уклад Единой Описи Структурных Типов:** обеспечивает самобытное состоятельное полное описание устроев, естественно зримо и верно отражающее меры и состав описываемых устройных типов;
* **Последовательное наследование типов и архетипов:** обеспечивает возможность описи новых типов на основе базовых первородных образов (архетипов) без повторений одинаковых логических выражений;
* **Надзор качества прямого управления:** обеспечивает возможность надзора за соблюдением мер данных, полностью исключающий их неявное усечение, посредством неразрывного содействия с `gas`.

## 💻 Боевые примеры использования

### Наследование и Использование Архетипов и Типов
```c
typedef t_n10,		t_vnsh_k	// Технически возможно указывать разделитель ','
typedef t_b08		t_vntr_k	// Технически возможно не указывать разделитель ','
typedef t_vnsh_k	t_dln_k		// Обеспечено последовательное наследование Архетипов

RZDL_0(PRM, "a", @progbits);
	prm_1:	t_vntr_k	0xAA			// Соберётся успешно
	prm_2:	t_vntr_k	0xAABB			// Соберётся успешно
	prm_3:	t_dln_k		0xAABBCC		// ОШИБ НАРУШЕНИЕ МЕРЫ ТИПА (ПРИ СОБЛЮДЕНИЕ ПРЕДЕЛЬНОЙ МЕРЫ РАЗРЯДНОСТИ АППАРАТНОГО ВЫЧИСЛИТЕЛЯ 32/64)
	prm_4:	t_dln_k		0xAABBCCDDEE	// ОШИБ НАРУШЕНИЕ МЕРЫ ТИПА (ПРИ НАРУШЕНИИ ПРЕДЕЛЬНОЙ МЕРЫ РАЗРЯДНОСТИ АППАРАТНОГО ВЫЧИСЛИТЕЛЯ 32/64)
RZDL_1(PRM, "a", @progbits);
```
